引数: $ARGUMENTS

モードの切り替えはフックが処理済みで、その結果を `<claude-toolkit>` として渡している。

- 引数がなければ、「作業モードにしました。」と 1 行だけ伝えて終える。作業や提案を始めない
- 引数が「ok」か「OK」で始まるときは、次の「ok のとき」に従う
- それ以外の引数があれば、それを作業モードでのユーザーの発言として扱い、そのモードのルールで応答する
- `<claude-toolkit>` が渡されていなければ、「モードのフックが入っていません。claude-toolkit の install を実行してください」とだけ伝えて終える

## ok のとき
1. 会話をさかのぼり、それまでに決まったことと、AI が出してまだ答えをもらっていない論点を集める。後で答えが出た論点や、取り下げた論点は除く。
2. ok のあとに文が続いていれば、追加の指示として扱う。外すと書かれた論点は、決めずに残す。
3. 残りの論点を、それぞれの推奨どおりに決める。推奨の中身は変えない。推奨に条件が付いていれば、条件ごと決める。推奨が付いていない論点は、決めずに残す。
4. 決まったことと、推奨どおりに決めたことで、作業モードのルールに沿って作業を始める。
5. 作業の報告に、推奨どおりに決めたことを 1 件 1 行で添える。決めずに残した論点があれば、残した理由とあわせて書く。
6. ボードが紐づいていれば、推奨どおりに決めたことを、ボードの決定事項に足す。
7. 決まったことも、答えていない論点も無ければ、「進める内容がありません」とだけ返す。
