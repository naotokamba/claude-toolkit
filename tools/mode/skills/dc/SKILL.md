引数: $ARGUMENTS

モードの切り替えはフックが処理済みで、収束モードになっている。その結果を `<claude-toolkit>` として渡している。

- `<claude-toolkit>` が渡されていなければ、「モードのフックが入っていません。claude-toolkit の install を実行してください」とだけ伝えて終える
- 引数が無く、直前までの会話からも議題が読み取れなければ、「/dc のあとに、何について決めたいかを書いてください」とだけ伝えて終える

## 手順
1. 議題は引数の文にする。引数が無ければ、直前までの会話で決めようとしていたことを議題にする。
2. 発散を、Agent ツールの fork のサブエージェント 1 つに任せる。fork は会話をそのまま引き継ぐので、事情を書き直さなくてよい。fork には次の指示を渡す。
   - 議題について、目的を達成する手段を広く出す。目の前の改善に加えて、制約そのものを動かす案や、上への提案、仕様変更の打診も含める
   - 過去事例、既存のコードや仕組み、直近に世に出たベストプラクティスを調べ、それをもとに広げる
   - 良し悪しの判断と絞り込みはしない。1 案 1 行で、名前と短い説明の一覧を返す
3. fork が使えないときは、議題と、ここまでの会話の要点を添えて、普通のサブエージェントに同じ指示で発散させる。
4. 受け取った一覧は、ユーザーに見せない。その一覧を発散で出た選択肢として、収束モードのルールで絞り、論点 1 件と推奨を出す。
5. 論点の前に、「この件」として、何をする件かと、どんな困りごとから生まれた件かを 1 行ずつ書く。読み手は、別の件から切り替わってきたばかりで、この件の経緯を覚えていない。起点の issue やカードが分かっていれば、その言葉にリンクを付け、分からなければ分からないと書く。
