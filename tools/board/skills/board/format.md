# ボードのデータの形

ボードの中身は、アーティファクトのデータベースに置く。ページは表示するだけで、書き換えない。
ここに無い欄は作らない。経緯、根拠、メモを書く欄は無い。残したいものは issue か、ボードとは別のアーティファクトに書く。
`claude-toolkit board check` が、この形と字数の上限を検査する。

## 文書 meta/board
| 欄 | 中身 | 上限 |
|---|---|---|
| title | ボードの名前 | 40 字 |
| purpose | そもそも何のためか。1 文 | 80 字 |
| goal | ボード全体のゴール。1 文 | 80 字 |
| updated | 最終更新日 `YYYY-MM-DD` | |
| report | 直近の報告 `{result, text}`。result は「完遂した」か「完遂できなかった」。text は 1 文 | text 80 字 |
| decisions | 決定事項の配列 `[{text, date}]`。date は `YYYY-MM-DD` | text 80 字 |
| issue | issue に書き出すときの決まり `{repo, prefix, parentPrefix}`。repo は `owner/name`。prefix は子の題の頭、parentPrefix は親の題の頭。省略できる | |

title だけは必須。

## 集まり cards の文書 cards/<id>
id は英数字と `-` `_` だけ。

| 欄 | 中身 | 上限 |
|---|---|---|
| title | カードの名前。話題を 1 つ | 30 字 |
| goal | このカードのゴール。1 文 | 80 字 |
| state | 「進行中」「issueに移した」「別途やる」「済み」のどれか | |
| order | 並び順の数 | |
| issue | 親 issue `{url, label}`。issue に移したとき。省略できる | |
| tasks | 作業の配列 | |

title、goal、state、order は必須。

### 作業 tasks の 1 件
| 欄 | 中身 | 上限 |
|---|---|---|
| id | カードの中で重ならない短い文字列 | |
| text | 何をするか | 60 字 |
| kind | 「やるだけ」「判断待ち」「済み」のどれか | |
| owner | 「あなた」「AI」「ほかの人」のどれか。省略できる | |
| issue | `{url, label}`。省略できる | |
| ronten | 論点。kind が「判断待ち」のときだけ書き、そのときは必須 | |

### 論点 ronten
収束モードのルールで整理し終えた形にする。調べれば分かることは調べてから書く。経緯と目的から答えが自明な問いは書かない。

| 欄 | 中身 | 上限 |
|---|---|---|
| question | 答えによって選ぶ道が変わる問い。必須 | 80 字 |
| materials | 判断材料。5 つまで | 各 80 字 |
| recommend | 推奨と、その理由。必須 | 120 字 |
| shaken | 揺らいだ決定事項。decisions の文言を写す。省略できる | 80 字 |
| ifDo | まだ相談の段階のとき、こうならやる。省略できる | 80 字 |
| ifDont | まだ相談の段階のとき、こうならやらない。省略できる | 80 字 |
| notFound | 探したが見つからなかったもの。3 つまで。省略できる | 各 80 字 |

## 手元に置くときの並び
データベースの読み出しで `out_dir` を使うと、次の並びで書き出される。検査も同じ並びを読む。
```
<フォルダ>/meta/board.json
<フォルダ>/cards/<id>.json
```
