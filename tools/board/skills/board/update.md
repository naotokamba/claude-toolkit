# ボードの更新

このセッションに紐づいたボードを、次の節目で更新する。節目でないときは更新しない。

| 節目 | 変えること |
|---|---|
| 論点にユーザーが答えたとき | decisions に 1 件足す。その作業の kind を「やるだけ」に変え、ronten を消す |
| 作業をしてターンを返すとき | 終わった作業を「済み」にする。新しく出た作業と判断待ちを足す。report を今回の報告に書き換える。updated を今日にする |
| 目的を記録したとき | ボードの purpose が空なら書く。空でなければ変えない |

## 手順
1. データベースを読む道具で、`meta` と `cards` を作業用のフォルダに書き出す。ArtifactData の list、または Artifact の read_db に `out_dir` を付ける。結果に出る各文書の version を控える。
2. 直す前に、書き出したままの状態で検査のコマンドを通す。通らなければ、何も書かずに止め、ボードの形が違うことを報告で伝える。既にあるデータを形に合わせて削ったり書き換えたりしない。
3. JSON を直す。形は同じフォルダの format.md に従う。
4. もう一度、検査のコマンドを通す。自分が直した部分が通らなければ、通るまで直す。
5. 変えた文書だけを batch でまとめて書く。既にある文書には、控えた version を if_version に付ける。
6. 書き込んだ文書を読み直し、変わっていることを確かめる。

## 決まり
- 経緯、根拠、メモの欄を足さない。
- 済んだカードは state を「済み」にする。消さない。
- ページの HTML は触らない。
- 更新したことを、報告の中で長く書かない。
