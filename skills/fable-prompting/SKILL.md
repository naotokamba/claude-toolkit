Fable 5.2 の別セッションに渡す指示文を、これから一緒に作ります。流れは次のとおりです。

1. あなたとユーザーが、このセッションで対話して指示文を作る。
2. ユーザーが承認したら、あなたがその指示文で Fable 5.2 の別セッションを作る。仕事を進めるのは、その Fable です。
3. その Fable が、実装などを Opus 5.5 のサブエージェントに渡す。

始める前に、このスキルのフォルダにある Anthropic の公式資料を読んでください。指示文は、あなたの記憶ではなくこの資料に沿って作りたいからです。

- `prompting-claude-fable-5-2.md`: Fable 5.2 専用の指示の出し方。全部読んでください。
- `claude-prompting-best-practices.md`: 全モデルに共通する指示の出し方。長いので、必要な節だけ読んでください。
- `whats-new-fable-5-2.md`: Fable 5.2 の能力と変更点。必要になったら開いてください。

## 指示文に要る 3 つ

ユーザーが別セッションを作るよう言ったとき、次の 3 つのうち会話に出ていないものがあれば、作る前に伝えてください。

- **ゴール**: 何のための仕事か、誰のためか、終わったと言える状態は何か。
- **資料の場所**: issue、Notion のチケット、Slack のスレッドなどの URL。
- **任せる範囲**: 聞かずに進めてよい操作と、先に聞いてほしい操作。

別セッションは、あなたが Fable 5.2、effort は high で作ります。作る前に、指示文をユーザーに見せて承認を得てください。続きの仕事のときは、新しく作らず、同じ Fable のセッションに次の指示文を送ってください。

## 指示文に入れること

Fable は Opus の 2 倍の料金なので、Fable でなければ質が出ない仕事に絞りたいです。指示文には、次のことを理由と一緒に入れてください。

- 実装、テスト、デバッグは、Opus 5.5、effort は medium のサブエージェントに渡す。Fable 自身は、設計、判断、サブエージェントへの指示、返ってきた結果の確認をする。
- これは費用のための目安で、質より優先しない。Opus が詰まるときは、まず effort を上げ、それでも進まなければ Fable が引き取る。
- Sonnet は使わない。Sonnet に回せる仕事の線引きを、まだ決めていないため。
