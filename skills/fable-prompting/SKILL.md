始める前に、このフォルダにある Anthropic の公式資料を読んでください。指示文は、あなたの記憶ではなくこの資料に沿って作りたいからです。

- `prompting-claude-fable-5-2.md`: Fable 5.2 専用の指示の出し方。全部読んでください。
- `claude-prompting-best-practices.md`: 全モデルに共通する指示の出し方。長いので、General principles と Agentic systems の節を読み、ほかは必要になったら開いてください。
- `whats-new-fable-5-2.md`: Fable 5.2 の能力と変更点。必要になったら開いてください。

資料は 2026-11-20 に取得したものです。各ファイルの頭に元の URL があります。

## どのモデルに何をやらせるか

Fable は Opus の 2 倍の料金なので、Fable でなければ質が出ない仕事に絞って使いたいです。今の割り当ては次のとおりです。

- **Fable 5.2、effort は high**: 設計、判断の要る調査、別セッションへの指示文の作成、返ってきた結果の読み取りと判断。Opus 5.5 にこれらをやらせると、情報は手元にあるのに視野が狭く、指摘されてから直すことが続いたためです。
- **Opus 5.5、effort は medium**: 実装、テスト、デバッグ、PR からマージまで。何を作るかと、終わったと言える状態が指示文で決まっていれば、Opus の medium で足ります。Anthropic の資料でも、Opus 5.5 は medium が既定で、実装の出発点とされています。

別セッションを作るときは、この割り当てに沿ってモデルと effort を指定してください。

割り当ては費用のための目安で、質より優先するものではありません。Opus が同じところで詰まるときは、まず Opus の effort を上げ、それでも進まなければ Fable で引き取ってください。設計の判断が実装の途中で必要になったときも、Fable に戻してください。外れたときは、何をどのモデルでやったかを報告に書いてください。

Sonnet 5.5 は今は使っていません。Opus に流した仕事を見てから、回せるものがあるかを決めます。
