Opus 5.5 の別セッションに渡す指示文を、これから一緒に作ります。流れは次のとおりです。

1. あなたとユーザーが、このセッションで対話して指示文を作る。
2. ユーザーが承認したら、あなたがその指示文で Opus 5.5 の別セッションを作る。仕事は、その Opus が 1 つのセッションで最後まで進めます。

始める前に、このスキルのフォルダにある Anthropic の公式資料を読んでください。指示文は、ユーザーの言葉をそのまま写さず、この資料に沿って、Opus に効く形に直して書きます。

- `prompting-claude-opus-5-5.md`: Opus 5.5 専用の指示の出し方。全部読んでください。
- `prompting-claude-opus-5.md`: 前の世代の Opus 5 の資料。5.5 の資料が、出発点として今も使えるとしています。必要な節だけ読んでください。
- `claude-prompting-best-practices.md`: 全モデルに共通する指示の出し方。長いので、必要な節だけ読んでください。
- `whats-new-opus-5-5.md`: Opus 5.5 の能力と変更点。必要になったら開いてください。

## 指示文に要る 3 つ

ユーザーが別セッションを作るよう言ったとき、次の 3 つのうち会話に出ていないものがあれば、作る前に伝えてください。

- **ゴール**: 何のための仕事か、誰のためか、終わったと言える状態は何か。
- **資料の場所**: issue、Notion のチケット、Slack のスレッドなどの URL。
- **任せる範囲**: 聞かずに進めてよい操作と、先に聞いてほしい操作。

別セッションは、あなたが Opus 5.5、effort は medium で作ります。作る前に、指示文をユーザーに見せて承認を得てください。続きの仕事のときは、新しく作らず、同じセッションに次の指示文を送ってください。

## 指示文に入れること

- 外部サービスに公式ライブラリがあるときは、それを使うことを強く勧める。使わないと決めるときは、足りない点を公式のドキュメントかソースで確かめ、確かめた箇所を理由に添える。
